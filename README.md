# SPANDA-Smart-Power-Analytics-using-Numerical-Data-Analysis
SPANDA is a Smart Power Analytics framework for Numerical Data Analysis, using PCA-based K-Means clustering to identify and profile building-level electricity consumption patterns and subsequently analyse anomalous behaviour.

Dataset: iBlend- https://springernature.figshare.com/articles/dataset/Energy_dataset_of_IIITD/6007637?backTo=/collections/I-BLEND_a_campus_scale_commercial_and_residential_buildings_electrical_energy_dataset/3893581
